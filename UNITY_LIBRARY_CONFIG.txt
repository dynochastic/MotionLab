This document contains all necessary configurations for integrating Unity library

================================================================================
1. UNITY LIBRARY BUILD.GRADLE (unityLibrary/build.gradle)
================================================================================

CRITICAL CONFIGURATIONS:
------------------------
✓ Use Android Studio NDK (DO NOT set custom ndkPath - let Gradle use Android Studio's NDK)
✓ ndkVersion: "29.0.14033849" (must match app/build.gradle.kts)
✓ Remove any buildToolsVersion override
✓ Define ext.unityStreamingAssets = "" BEFORE the android {} block
✓ aaptOptions.noCompress: Must use project.ext.unityStreamingAssets.tokenize(', ')
✓ packagingOptions: doNotStrip '*/arm64-v8a/*.so' + jniLibs.useLegacyPackaging = true
✓ IL2CPP task: Environment variables ANDROID_SDK_ROOT and ANDROID_NDK_ROOT must be set
✓ sourceSets.main.jni.srcDirs = ["src/main/Il2CppOutputProject"]

REQUIRED CODE STRUCTURE:
------------------------
1. Top-level dependencies:
   dependencies {
       implementation fileTree(dir: 'libs', include: ['*.jar'])
       implementation project('mobilenotifications.androidlib')
   }

2. Define streaming assets (BEFORE android {} block):
   ext.unityStreamingAssets = ""

3. Android block:
   android {
       namespace "com.unity3d.player"
       compileSdkVersion 35
       ndkVersion "29.0.14033849"
       
       compileOptions {
           sourceCompatibility JavaVersion.VERSION_11
           targetCompatibility JavaVersion.VERSION_11
       }
       
       defaultConfig {
           minSdkVersion 26
           targetSdkVersion 35
           ndk {
               abiFilters 'arm64-v8a'
           }
           versionCode 1
           versionName '1.0.2'
           consumerProguardFiles 'proguard-unity.txt'
       }
       
       lintOptions {
           abortOnError false
       }
       
       aaptOptions {
           noCompress = ['.unity3d', '.ress', '.resource', '.obb', '.bundle', '.unityexp'] + 
                        project.ext.unityStreamingAssets.tokenize(', ')
           ignoreAssetsPattern = "!.svn:!.git:!.ds_store:!*.scc:!CVS:!thumbs.db:!picasa.ini:!*~"
       }
       
       packagingOptions {
           doNotStrip '*/arm64-v8a/*.so'
           jniLibs {
               useLegacyPackaging true
           }
       }
   }

4. IL2CPP Build Function (CRITICAL):
   - Executable path: src/main/Il2CppOutputProject/IL2CPP/build/deploy/il2cpp(.exe)
   - MUST NOT include netcoreapp3.1 in path
   - Environment variables:
     * ANDROID_SDK_ROOT = getSdkDir() (from local.properties)
     * ANDROID_NDK_ROOT = android.ndkDirectory
   - Command line args must include:
     * --compile-cpp
     * --platform=Android
     * --architecture=arm64
     * --outputpath=.../jniLibs/arm64-v8a/libil2cpp.so
     * --baselib-directory=.../jniStaticLibs/arm64-v8a
     * --configuration=Release
     * --dotnetprofile=unityaot-linux
     * --tool-chain-path=android.ndkDirectory

5. IL2CPP Task Hook:
   afterEvaluate {
       if (project(':unityLibrary').tasks.findByName('mergeDebugJniLibFolders'))
           project(':unityLibrary').mergeDebugJniLibFolders.dependsOn BuildIl2CppTask
       if (project(':unityLibrary').tasks.findByName('mergeReleaseJniLibFolders'))
           project(':unityLibrary').mergeReleaseJniLibFolders.dependsOn BuildIl2CppTask
   }

6. Source Sets:
   sourceSets {
       main {
           jni.srcDirs = ["src/main/Il2CppOutputProject"]
       }
   }

5. UNITY BRIDGE ACTIVITY (UnityBridgeActivity.kt)
================================================================================

KEY REQUIREMENTS:
-----------------
✓ Launch UnityPlayerActivity via startActivityForResult(requestCode=2001)
✓ Set RESULT_OK BEFORE calling finish() - NEVER use postDelayed()
✓ Always include unity_success=true in result intent extras
✓ Handle onActivityResult, onBackPressed, and finish() methods
✓ Implement onLowMemory() and onTrimMemory() for memory management
✓ Initialize UnityDebugLogger and UnityCrashFixer in onCreate()

CRITICAL CODE PATTERNS:
-----------------------
1. onCreate():
   - Initialize logging and crash fixes
   - Set result intent with RESULT_OK BEFORE launching Unity
   - Launch Unity via startActivityForResult()

2. onActivityResult():
   - Create result intent with unity_finished=true, unity_success=true
   - Set RESULT_OK immediately
   - Call finish() immediately (NO DELAYS)

3. onBackPressed():
   - Create result intent with unity_back_pressed=true, unity_success=true
   - Set RESULT_OK immediately
   - Call finish() immediately (NO DELAYS)

4. finish():
   - Always set RESULT_OK with result intent before calling super.finish()
   - Include unity_success=true in extras

5. Memory Management:
   - onLowMemory(): Call System.gc()
   - onTrimMemory(): Handle TRIM_MEMORY_RUNNING_* levels

IMPORTANT: Removing postDelayed() calls was critical to prevent app quit/restart
           issues. Always set result and finish immediately.

7. WIRELESS DEBUGGING TIMEOUT FIXES
================================================================================

PROBLEM:
--------
When using wireless debugging, Android Studio times out after ~3 minutes while
waiting for the Unity app to start. This happens because:
- Unity IL2CPP compilation and native library extraction takes longer over WiFi
- Unity runs in a separate process (:Unity) which takes additional time to start
- Wireless debugging has higher latency than USB/AVD connections
- Android Studio's default timeout (300000ms = 5 minutes) may not be enough

SOLUTION - ANDROID STUDIO SETTINGS:
------------------------------------
1. File > Settings > Build, Execution, Deployment > Deployment
   - Install Timeout (ms): 900000 (15 minutes)
   - Launch Timeout (ms): 900000 (15 minutes)
   - Uncheck "Deploy as Instant App"
   - Check "Uninstall before launching" (optional, but helps avoid conflicts)

2. Alternative: Use "Do not launch Activity" option
   - Run > Edit Configurations > General tab
   - Launch: "Nothing" or "Do not launch Activity"
   - After build completes, manually open app from device launcher
   - Then attach debugger: Run > Attach debugger to Android process

3. For wireless debugging stability:
   - Ensure device and computer are on same WiFi network (prefer 5GHz)
   - Disable VPN/Private DNS if active
   - Keep device screen awake during deployment
   - In Developer options: "Wait for debugger" = OFF
   - Re-pair wireless debugging if connection is unstable

SOLUTION - GRADLE BUILD OPTIMIZATION:
-------------------------------------
1. Use incremental builds (already enabled in IL2CPP task)
2. Build only for arm64-v8a (already configured)
3. Use Release configuration for IL2CPP (faster than Debug)

SOLUTION - INSTALL-ONLY APPROACH:
----------------------------------
Instead of "Run" (which waits for app launch), use:
1. Build > Build Bundle(s) / APK(s) > Build APK(s)
2. Install APK manually via: adb install app/build/outputs/apk/debug/app-debug.apk
3. Launch app manually from device
4. Attach debugger if needed

ADB COMMANDS FOR WIRELESS DEBUGGING:
-------------------------------------
# Connect to wireless device
adb connect <device_ip>:<port>

# Check connection
adb devices

# Install APK
adb install -r app/build/outputs/apk/debug/app-debug.apk

# Launch app
adb shell am start -n com.example.motionlab/.MainActivity

# View logs
adb logcat | grep -E "Unity|MotionLab|UnityBridge"

# Kill ADB server if issues
adb kill-server
adb start-server

9. COMMON ISSUES AND SOLUTIONS
================================================================================

ISSUE: "Could not get unknown property 'unityStreamingAssets'"
SOLUTION: Define ext.unityStreamingAssets = "" BEFORE android {} block

ISSUE: "Resources$NotFoundException: Resource ID #0x0"
SOLUTION: Ensure both strings.xml files contain game_view_content_description

ISSUE: "IL2CPP executable not found"
SOLUTION: Verify path is src/main/Il2CppOutputProject/IL2CPP/build/deploy/il2cpp(.exe)
         (NOT netcoreapp3.1/il2cpp.exe)

ISSUE: "NDK version mismatch"
SOLUTION: Ensure both unityLibrary/build.gradle and app/build.gradle.kts use
         ndkVersion "29.0.14033849"

ISSUE: "App quits/restarts after returning from Unity"
SOLUTION: 
  - Remove all postDelayed() calls in UnityBridgeActivity
  - Set RESULT_OK immediately before finish()
  - Include unity_success=true in result intent extras
  - Verify noHistory="false" in AndroidManifest

ISSUE: "Wireless debugging timeout"
SOLUTION:
  - Increase Android Studio timeout settings (900000ms)
  - Use "Do not launch Activity" and launch manually
  - Or use install-only approach with adb install
  - Ensure stable WiFi connection (5GHz preferred)

ISSUE: "Unity native libraries not found"
SOLUTION:
  - Verify extractNativeLibs="true" in AndroidManifest
  - Verify jniLibs.useLegacyPackaging = true in both build.gradle files
  - Check that libil2cpp.so is in jniLibs/arm64-v8a/

ISSUE: "Back button doesn't work in Unity"
SOLUTION:
  - Verify Back_Button_Handler_Improved.cs is in Unity project
  - Verify UnityBridgeActivity.returnToAndroid() is exposed
  - Check logcat for Unity->Android communication logs
  - Verify Unity script is calling AndroidJavaObject methods correctly
