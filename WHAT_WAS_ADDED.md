1. **All Source Code**
   - All `.kt` files (Kotlin source code)

   - C/C++ files in Unity library

2. **All Resources**
   - Images (PNG, JPG, etc.)
   - Layouts and UI files
   - Fonts
   - Videos

   - Assets (lesson images, exercises, transcripts)

3. **Project Configuration**
   - `build.gradle.kts` files

4. **Unity Library Source**
   - Unity library source code

   - Unity assets and resources

5. **Documentation**
   - `.md` files (markdown documentation)

## ❌ EXCLUDED (Won't be pushed):

1. **Build Artifacts**
   - `/build` directories (compiled code)
   - `.gradle` directories (Gradle cache)
   - All build outputs

2. **IDE Files**
   - `.idea/modules/` (IDE-generated module files)
   - `.idea/caches/`
   - `.idea/workspace.xml`
   - `.idea/libraries/`
   - `*.iml` files

3. **Local Configuration**
   - `local.properties` (local paths, API keys)
   - User-specific settings

4. **Temporary Files**
   - `.tmp`, `.bak`, `.swp` files

This ensures your repository contains all the source code needed to build the project, but excludes large build artifacts and personal IDE settings.
